# Accepted design baseline

User accepted current Open Design project “Home Security Video Alignment” on 2026-08-25 after direct in-app refinements.

Implementation authority is current four-stage product model: Library → Align → Cut → Review; source-only alignment; one-source Program Video; independent Program Audio; wall-clock or source-clip cut anchoring; explicit gap/overlap reconciliation; provenance/fidelity review and render gate.

Open Design remains visual authority. Product naming in code is generalized to Room Alignment and ingestion is vendor-agnostic per subsequent user requirement.
