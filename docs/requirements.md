# Product requirements

The accepted product requirements are the fixed `REQ-001` through `REQ-150` contract supplied for this delivery. The concise implementation/evidence disposition for every requirement is maintained in [requirements-ledger.md](requirements-ledger.md). Normative serialization details live in `contracts/`; implementation choices and safety boundaries live in the architecture, security, dependency, API, and runbook documents.

The functional completion gate remains: vendor-neutral read-only library; permissive provenance; explicit logical sources; reversible affine alignment; exactly one program video selection; independently compiled single-source audio or explicit silence; honest gaps/ambiguity; revision-bound review; recoverable video/manifest pair; durable restart behavior; generated API client; and representative 26,000-plus asset evidence.
